# Style Guide Prototype

A comprehensive style guide prototype featuring common UI components with CSS variables and flexbox layouts.

## Features

- Comprehensive UI component showcase (alerts, badges, buttons, cards, forms, lists, navigation, tables, typography)
- CSS variables for design tokens (colors, spacing, font sizes, etc.)
- Flexbox-based layouts
- No abbreviations in class names
- Alphabetically sorted CSS properties
- Normalize.css for consistent cross-browser styling
- Biome for CSS linting
- Prettier for HTML formatting

## Quick Start

```bash
npm install
```

## Scripts

- `npm run lint` - Run linters for HTML and CSS
- `npm run format` - Format HTML and CSS files
- `npm run lint:html` - Check HTML formatting
- `npm run lint:css` - Check CSS linting
